URL Apps Script belum diatur

Buka file index.html, lalu ganti nilai APPS_SCRIPT_URL dengan URL Web App Apps Script milik Anda.

const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycbxxxx/exec";

Membuka Portal Donasi

Mohon tunggu sebentar. Aplikasi sedang menghubungkan ke server Apps Script.

Internet Terputus

Aplikasi membutuhkan koneksi internet untuk mengakses server Apps Script. Sambungkan internet lalu buka kembali aplikasi.

Update Aplikasi Tersedia

Versi baru sudah tersedia. Untuk keamanan dan kestabilan data, aplikasi tidak dapat digunakan sebelum diperbarui.
